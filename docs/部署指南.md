# 部署指南（保姆级 · 零基础）

本项目是**纯 CPU、轻量级**的 Python 程序，不需要 GPU、不需要 AutoDL，
普通笔记本 / 台式机 + PyCharm 就能跑完。下面从零开始一步步走。

预计耗时：首次配置约 10 分钟，之后跑一次实验只需几秒。

---

## 第 0 步：确认你要装的东西

| 软件 | 作用 | 下载地址 |
|---|---|---|
| Python 3.9+ | 运行环境（建议 3.10 / 3.11） | https://www.python.org/downloads/ |
| PyCharm Community | 写代码/跑代码的 IDE（社区版免费够用） | https://www.jetbrains.com/pycharm/download/ |
| Git（可选） | 拉代码；不装也能用网页下载 zip | https://git-scm.com/downloads |

> Windows 装 Python 时，安装界面**务必勾选 “Add Python to PATH”**，否则命令行找不到 python。

---

## 第 1 步：拿到代码

**方式 A（推荐，用 Git）**
```bash
git clone <你的仓库地址>.git
cd LLM-Enhanced-Expensive-Optimization-Solver
git checkout claude/llm-evolutionary-algorithm-o5tqdk
```

**方式 B（不想装 Git）**
在 GitHub 仓库页面把分支切到 `claude/llm-evolutionary-algorithm-o5tqdk`，
点绿色 `Code` → `Download ZIP`，下载后解压到任意文件夹。

---

## 第 2 步：用 PyCharm 打开并建虚拟环境

1. 打开 PyCharm → `Open` → 选中项目文件夹（含 `requirements.txt` 的那层）。
2. PyCharm 通常会弹窗提示 **“Create virtual environment”**，直接点 **OK**
   （它会在项目里建一个隔离的 `venv`，不污染系统 Python）。
   - 如果没弹窗：`File → Settings → Project → Python Interpreter →
     Add Interpreter → Add Local Interpreter → Virtualenv → OK`。

> 虚拟环境 = 给这个项目单独开一个"干净房间"装依赖，避免和别的项目冲突。

---

## 第 3 步：装依赖

在 PyCharm 底部的 **Terminal**（终端）里输入：
```bash
pip install -r requirements.txt
```
只装 3 个包（numpy / scipy / matplotlib），几十秒完成。

> 国内网慢的话，可用清华镜像加速：
> `pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`

---

## 第 4 步：离线跑一次（无需任何 API key）

这一步用内置的模拟 LLM，验证环境没问题、并产出全部结果图表：
```bash
python -m experiments.run_experiment --seeds 5 --dim 10 --fes 300
```
跑完去 `results/` 文件夹看：
- `convergence.png` —— 收敛曲线图
- `summary.csv` —— 各方法最终结果
- `llm_cost.csv` —— LLM 成本对比

再跑一下单元测试，确认核心逻辑正确：
```bash
python tests/test_core.py     # 应输出 ALL TESTS PASSED
```

> **常见报错 `No module named 'src'`**：说明运行目录不对。
> 解决：确保命令是在**项目根目录**下执行（Terminal 里 `pwd`/`cd` 到根目录），
> 并且用 `python -m experiments.run_experiment` 这种 `-m` 方式跑，最稳。
> 若右键运行某个 .py 报这个错：编辑运行配置，把
> **Working directory 设成项目根目录**。

---

## 第 5 步（可选）：接真实 LLM（以 aihubmix 为例）

前四步已经能交作业了。想用真实 GPT 模型再做这步。

### 5.1 申请 API key
1. 打开 https://aihubmix.com ，注册登录。
2. 充值一点额度（跑几轮实验花费很小）。
3. 在控制台找到 **API Keys**，新建一个 key，形如 `sk-xxxxxxxx`，复制备用。

### 5.2 在 PyCharm 里配置（推荐图形方式，不用记命令）
`Run → Edit Configurations → 选中 run_experiment →
Environment variables` 里点右边小图标，逐条添加：

| 变量名 | 值 |
|---|---|
| `LLM_API_KEY` | `sk-xxxxxxxx`（你的 key） |
| `LLM_BASE_URL` | `https://aihubmix.com/v1` |
| `LLM_SMALL_MODEL` | `gpt-3.5-turbo` |
| `LLM_LARGE_MODEL` | `gpt-4o-mini` |

在 `Parameters` 里填 `--real --seeds 3`，然后点运行。

### 5.3 或者用命令行配置
**macOS / Linux：**
```bash
export LLM_API_KEY="sk-xxxxxxxx"
export LLM_BASE_URL="https://aihubmix.com/v1"
export LLM_SMALL_MODEL="gpt-3.5-turbo"
export LLM_LARGE_MODEL="gpt-4o-mini"
python -m experiments.run_experiment --real --seeds 3
```
**Windows PowerShell：**
```powershell
$env:LLM_API_KEY="sk-xxxxxxxx"
$env:LLM_BASE_URL="https://aihubmix.com/v1"
$env:LLM_SMALL_MODEL="gpt-3.5-turbo"
$env:LLM_LARGE_MODEL="gpt-4o-mini"
python -m experiments.run_experiment --real --seeds 3
```

> ⚠️ 真实模式每次评价都要调网络 API，会**慢很多也会花钱**，建议先用
> `--seeds 1` 小规模试通，再逐步加大。key 不要提交到 GitHub。

## 常见问题速查

| 现象 | 原因 / 解决 |
|---|---|
| `No module named 'src'` | 不在项目根目录跑；用 `python -m ...` 且工作目录设为根目录 |
| `pip` 很慢或超时 | 加清华镜像 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |
| `python` 命令找不到 | 装 Python 时没勾 Add to PATH；重装或改用 `py`（Windows） |
| 真实模式报 401/403 | key 错、没充值、或 BASE_URL 写错 |
| 真实模式很慢 | 正常，API 有网络延迟；先用 `--seeds 1` |
| 图中文乱码 | 本项目图内是英文，不受影响；如需中文标题另配字体 |

---

## 一句话总结
**本地 PyCharm：装 Python → 建虚拟环境 → `pip install -r requirements.txt`
→ `python -m experiments.run_experiment` 出结果。GPU / AutoDL 完全用不上。**
